## Must-fix for the spec

1. Delete (not just env-disable) in the public build: `scanner`, `sdk/ingest`, `sdk/stream`, `github-webhook`, `entity/expand`, `mcp`, `ai/analyze`, `ai/briefing`, and the whole `oi/*` tree (oi, assist, identify, models, runs, runs/[id], ask, events, inject). `oi/*` and `mcp` are only gated by `process.env.OI_DISABLED === '1'` (lib/oi/service.ts:23-25), which fails open if the var is absent. Prefer removing files, or invert the gate to `OI_ENABLED === '1'`. Better still: return 404 from a Next `redirects/rewrites` or an allowlist route manifest.
2. No paid key anywhere in the Worker environment: `GEMINI_API_KEY_1..8` (ai/*), `SDK_INGEST_KEY`, `SCANNER_KEY/URL`, `GITHUB_WEBHOOK_*`, `INTEL_URL`. Enforce with a CI check that greps the built worker's wrangler vars.
3. `ai/overview`: remove the Gemini branch (route.ts:331-338) so it is heuristic only; cap request body (~64 KB) and slice arrays in `digestChain` and `digestMarkets` (route.ts:54-62,208-255).
4. `chain/daily`: ignore `?refresh=1`, clamp `days` to a fixed set, add CDN caching headers. Keep the response `s-maxage=1800`.
5. `oi/trending` (if kept): add edge caching and drop `force-dynamic` so strangers cannot multiply Polymarket subrequests.
6. All remaining in-memory rate limiting is ineffective on Workers: `isRateLimited` is a per-isolate Map (lib/ssrf-guard.ts:219-233), as are per-route copies (ai/analyze:29, ai/briefing:29). Use Cloudflare WAF rate-limiting rules (or Rate Limiting binding) in front of `/api/*`. Treat the code limiters as cosmetic.
7. Workers compatibility: module-scope `setInterval` (ai/analyze/route.ts:51, ai/briefing/route.ts:50) and `node:dns/promises` (lib/ssrf-guard.ts:1) are believed to break on Workers (unverified); `maxDuration`, SSE and long-lived `setInterval` timers (mcp, oi events, sdk/stream) do not fit. `lib/ssrf-guard.ts` is imported by many routes outside this lane: if `lookup` is unsupported, importing it may fail at module load. Test `getClientIp`/`isRateLimited` imports separately from `validateHost`.
8. `health`: KEEP; optionally strip `nominatimStats()`.
9. Out of lane, flagged: `lib/oi/context.ts:167-181` and `mcp.ts:324` import the news, earthquakes and markets route handlers directly, so those routes' own fetch fan-out and cache/SSRF behaviour matter; they belong to another lane.
